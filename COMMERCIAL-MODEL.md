# Commercial Model

## Output-Only Licensing

ZeroShip does not sell source code, solver wrappers, or runtime APIs.

The commercial surface is **computational outputs**: vessel designs, engineering analysis packages, and reproducible result sets produced by the platform. Clients receive an output package — not the tooling that generated it.

## Internal Licensing Constraints

The platform codebase is governed internally by AGPL and GPL family licenses. These licenses apply to Zer0pa's internal development and contribution workflow. They do not create obligations for output recipients because **no source code is distributed to clients**.

No part of this repository is licensed for external use, modification, or redistribution. See [RIGHTS-AND-EXCLUSIONS.md](RIGHTS-AND-EXCLUSIONS.md) for the complete rights position.

## Partnership Categories

| Category | Relationship | What They Receive |
|----------|-------------|-------------------|
| **Data owners** | Provide OEM component data under bounded terms | Vessel designs that correctly embed their components with provenance |
| **OEM integrators** | Collaborate on plant, propulsor, or system selection | Analysis packages showing their equipment in governed vessel context |
| **Class societies** | Provide regulatory baselines and review criteria | Compliance-ready engineering documentation with full computation trail |
| **Shipyards** | Translate vessel concepts into production planning | Build-specification packages derived from platform outputs |

## Commercial Readiness

Current commercial status: **Research derivative viable**.

The platform has demonstrated end-to-end capability from definition through structural analysis, powering, and synthesis. Specific capabilities (motion prediction, seakeeping) remain in development. No output has received class approval or production certification.
