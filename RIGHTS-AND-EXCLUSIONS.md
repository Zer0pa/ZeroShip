**Date:** 2026-04-14
**Status:** Draft for owner and counsel review
**Intended use:** Public-facing legal notice for the ZeroShip showcase repo

## 1. What This Repository Is

This repository is a **public showcase and architecture surface** for ZeroShip.

It exists to explain:

- what ZeroShip is
- how the end-to-end ship-first platform is intended to work
- how the platform relates to vessel-design outputs
- what kinds of tools, data surfaces, and integration categories the programme is working with
- why the current commercial model centres on outputs rather than software distribution

This repository is **not** a release of the ZeroShip platform code, internal toolchain, model assets, training data, or deployable software.
