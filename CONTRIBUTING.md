# Contributing

Thanks for helping improve the public ZeroShip surface.

## Scope

- public documentation improvements
- typo fixes
- broken link fixes
- clearer public proof routing

## Out Of Scope

- requests for private code
- requests for operator access
- requests for partner data or runtime credentials

## Pull Requests

- keep changes atomic
- preserve the README contract
- keep proof anchors repo-local
- keep the public boundary explicit
